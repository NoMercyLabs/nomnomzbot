# Legacy parity ledger

Every behaviour of the legacy bot (`StoneyEagle/nomercy-bot`) that viewers see or hear, and whether
NomNomzBot matches it. Rule `legacy-parity-ledger` (Stoney, 2026-10-04): every partial or missing row is a
plan slice, stream-facing first. The legacy inventory is listed by script, not by hand, and
`python scripts/check-parity-ledger.py` fails when a legacy item has no row here, a row has an unknown
status, or a partial/missing row names a slice that is not in `SHORTCOMINGS-EXECUTION-PLAN.md`.
Closing a parity slice: fix it, set its rows to matched here, then run the check and close the slice.

Status: **matched** = same stream behaviour; **partial** = exists, differs (the gap says how);
**missing** = no equivalent; **n/a** = not stream behaviour; **open** = not yet checked.
